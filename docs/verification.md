## Проверки интерфейса

Встроенный Chromium браузер Codex, локальный HTTP-сервер. Проверены: пустой список; ошибки обязательных полей; создание еженедельного дела «Протереть стол» для кухни; сохранение при перезагрузке; отмена изменения названия; выполнение с созданием срока 20.11.2026 после исходного 13.11.2026; просмотр истории и фактического времени выполнения. Стандартный confirm оказался неудобен для автоматизированной проверки браузера, поэтому заменён доступным HTML-dialog с явными кнопками «Отмена» и «Подтвердить».

После замены повторно проверены отмена удаления, подтверждение удаления активного регулярного дела с сохранением выполненной истории, закрытие диалога клавишей Escape и создание дела клавишей Enter. Для просроченного разового дела напоминание показалось при запуске; после следующей перезагрузки повторного показа не было. При ширине окна 1280 пикселей ширина содержимого и клиентской области совпала (1265 пикселей с учётом вертикальной полосы прокрутки): горизонтального переполнения нет.

## Границы проверки

Отдельная приёмка на актуальной и предыдущей стабильных версиях Chrome и Edge, испытание 1000 дел на минимальном оборудовании и изменение часового пояса операционной системы не выполнялись. Номера этих версий не выдумываются. Модель хранит местные строки времени без UTC-конвертации; календарный расчёт использует setDate. Успешные проверки подтверждают проверенные сценарии, но не заменяют перечисленные приёмочные испытания.
