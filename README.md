# Планировщик уборки

Лабораторная работа № 1 «Разработка и управление требованиями к программному обеспечению».

**Вариант 11:** планировщик уборки — чек-лист регулярных и разовых дел по дому с напоминаниями.

Приложение предназначено для планирования уборки, просмотра предстоящих дел и отметки выполненных задач. В этом репозитории представлены требования к будущему приложению и задачи на его разработку.

## Документация

- [Техническое задание в Wiki](https://github.com/darazalilova-cpu/cleaning-planner-srs/wiki/Техническое-задание).
- [Задачи и критерии приёмки в Issues](https://github.com/darazalilova-cpu/cleaning-planner-srs/issues).

## Основные возможности

- Создание, редактирование и удаление дел по уборке.
- Планирование разовых и регулярных дел.
- Чек-лист с фильтрами по помещению, сроку и статусу.
- Отметка выполнения и создание следующего повторения.
- Напоминания в открытом приложении.
- Сохранение данных между запусками браузера.

## Состав работы

ТЗ содержит наименование и область применения, функциональные требования, требования к надёжности, интерфейсу и техническому обеспечению. Шесть Issues содержат User Stories, критерии приёмки и обратные ссылки на разделы ТЗ.

Работа посвящена анализу требований. Реализация приложения не входит в результат этой лабораторной работы.
