# v1.0.0 — Планировщик уборки

Первая версия учебного прототипа, вариант 11.

- Создание, редактирование, удаление и выполнение домашних дел.
- Помещения, сроки, совместные фильтры и история.
- Ежедневные, еженедельные и произвольные повторения.
- Напоминания в открытом приложении с сохранением признака показа.
- Локальное хранение и обработка ошибок без автоматического удаления данных.
- 25 задач беклога, четыре Milestones, Roadmap и документация.
- Отдельная SQLite-модель в 3NF, диаграмма PNG/SVG и тестовые данные.
- GitHub Actions, 10 тестов логики и 5 тестов БД.

Запуск: скачать Source code ZIP, распаковать и открыть index.html; рекомендуемый вариант — `python -m http.server 8000`, затем http://localhost:8000. Никаких ключей API, npm install и регистрации не требуется.

Ограничения: данные привязаны к браузерному профилю и адресу; очистка данных сайта удаляет их. Фоновые уведомления и синхронизация отсутствуют. SQLite-схема поставляется как самостоятельный результат лабораторной №4 и не подключена к localStorage-прототипу. Полная приёмка на двух версиях Chrome/Edge и минимальном оборудовании остаётся отдельной процедурой.
